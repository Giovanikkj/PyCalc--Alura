PyCalc 🧮

Um projeto simples, leve e educativo de uma Calculadora Básica desenvolvida em Python.

Este repositório faz parte da minha jornada inicial na imersão Alura, servindo para praticar lógica de programação, manipulação de dados de entrada e criação de funções em Python.

🚀 Funcionalidades
A calculadora executa as 4 operações matemáticas fundamentais, além do cálculo de porcentagem, via terminal:

➕ Soma

➖ Subtração

✖️ Multiplicação

➗ Divisão (com tratamento de erro para divisão por zero)

% Porcentagem

🛠️ Tecnologias Utilizadas
Python 3 (Linguagem de programação principal)

💻 Como Executar o Projeto
Se você quiser testar o código no seu computador ou no Google Colab, siga os passos abaixo:

Certifique-se de ter o Python instalado na sua máquina (ou acesse o Google Colab).

Copie o código contido no arquivo pycalc.py deste repositório.

Cole no seu ambiente de execução Python e aperte Play (ou execute via terminal com o comando python pycalc.py).
